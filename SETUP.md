# Publish your GitHub profile README

1. Open GitHub and create a **public** repository named exactly `simonasingh22`.
2. If GitHub says this is your special profile repository, confirm creation.
3. Extract this ZIP file.
4. Upload `README.md` and the complete `assets/` folder to the repository root.
5. Commit the files to the default branch.
6. Visit https://github.com/simonasingh22 to see the profile README.

## Important customizations

- The LeetCode card uses the public handle `simonasingh22`. If your LeetCode username differs, replace it in `README.md`.
- The profile uses the public portfolio URL and contact email supplied for this profile.
- All custom SVG artwork is stored locally in `assets/svg/`; you can edit the text and colors directly.
- GitHub profile README requirements: public repository, repository name matching your username, and a root-level `README.md`.
