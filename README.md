# 🏢 Sri Radhey Consultancy Website

### Transforming business enquiries into an organized digital workflow.

Many small businesses still rely on scattered communication channels like phone calls, WhatsApp messages, and emails to manage customer enquiries. As the number of enquiries grows, following up becomes difficult, information gets lost, and valuable leads are often missed.

I built **Sri Radhey Consultancy Website** to streamline that entire process.

Visitors can explore services, submit enquiries through an intuitive interface, and receive an instant confirmation experience while the backend securely stores every request and automatically notifies administrators.

Instead of manually tracking conversations, the consultancy now has a structured digital pipeline that makes every enquiry easier to manage.

### 💡 What this project demonstrates

- Designing scalable REST APIs
- Backend development using Express.js
- MongoDB database design
- Email notification integration
- Cloud deployment
- Production debugging
- Responsive frontend architecture

### 🌍 Real-world impact

✔ Faster enquiry management

✔ Better customer experience

✔ Organized business workflow

✔ Reduced manual follow-ups

# 🌍 LetsGo.com

### Making travel planning simpler, faster, and more enjoyable.

Planning a trip often involves switching between multiple websites to explore destinations, create bookings, and organize travel information.

I wanted to understand how modern travel platforms solve this problem.

So I built **LetsGo.com**, a Laravel-powered travel booking platform designed around the complete user journey.

Users can browse destinations, create bookings, authenticate securely, manage travel information, and interact with a clean, responsive interface backed by Laravel.

More importantly, this project helped me understand how large applications manage users, bookings, and complex database relationships.

### 💡 What this project demonstrates

- Laravel backend architecture
- MVC Design Pattern
- Authentication
- Database relationships
- Secure routing
- CRUD operations
- Responsive UI

### 🌍 Real-world impact

✔ Digital travel management

✔ Simplified booking process

✔ Organized customer information

✔ Better user experience

# 🏛 MuseBook

### Reimagining how museums handle online ticket bookings.

Museums shouldn't require visitors to stand in long queues just to purchase tickets.

MuseBook modernizes the visitor experience by allowing users to browse exhibitions, reserve tickets online, complete secure payments, and manage bookings from a single platform.

The project combines user-friendly design with backend workflows that manage authentication, bookings, payments, and administrative operations.

It was also one of my first opportunities to integrate a real payment gateway into a production-style application.

### 💡 What this project demonstrates

- Authentication system
- Payment gateway integration
- Database management
- Admin dashboard
- Chatbot integration
- Booking workflow
- Full-stack application development

### 🌍 Real-world impact

✔ Reduced booking friction

✔ Faster ticket reservations

✔ Secure online payments

✔ Improved visitor experience
